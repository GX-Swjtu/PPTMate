# 内置模板中文化维护说明

PPTMate 的内置模板不是 PPTX 文件。每套模板由 `template.json`、`static/` 静态资源和 `static/thumbnail.png` 缩略图组成。

本地化范围刻意限定为用户可见内容：

- 模板名称和简介；
- 版式示例中的标题、正文、列表、表格和图表标签；
- 版式的用户可见说明；
- 图片生成前显示的公共可替换图片占位图；
- 模板卡片缩略图。

组件 `id`、元素 `name`、协议枚举、资源路径、字体配置和组件内部说明保持上游原样，以降低后续合并冲突并避免改变模板生成协议。

上游更新模板后，重新应用中文化：

```bash
npm run localize:templates:zh-cn
npm run check:templates:zh-cn
```

转换脚本是幂等的。校验命令会阻止可见字段重新出现未批准的英文；`PPTMate`、`AI`、`ESG`、`KPI`、季度和数据单位等约定缩写除外。

为避免拉丁字体参数在中文回退字体上导致重叠或裁切，脚本还会将中文文本统一为 Noto 中文字体、零字距和不小于 1 的行高，校验命令会检查这些排版约束。

缩略图应从中文化后的首个版式重新渲染，并保留原预览中的示例照片。更新后需确认图片加载成功、中文没有溢出，且缩略图仍为 `1280 × 720` PNG。

内置模板导入时会为缩略图 URL 附加内容指纹；替换 `thumbnail.png` 后指纹会自动变化，无需要求用户手动清理浏览器长期缓存。
